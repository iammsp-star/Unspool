# Unspool (Open Source)

> A mobile application designed to curb short-form video addiction by tracking usage, setting hard limits, and offering gamified accountability.

## Full-Stack Emulation Environment
This repository contains a high-fidelity **Full-Stack Developer Preview** of Unspool built in React + TypeScript. It features a complete interactive mobile emulator, real-time Firebase state simulations, and a fully functional Accessibility Simulator Dev Console.

### Features
* **Reel Scroll Tracker Simulation:** Emulates tracking of YouTube Shorts, Snapchat, Instagram Reels, Facebook Reels, and TikTok.
* **Gamified Accountability:** Join "Reel Battles" to compete with friends.
* **Digital Wellbeing Controls:** Hard cooldown screens block access when you exceed your scroll limits.
* **Paywall:** Freemium tier architecture visualization.

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run the Development Server**
   ```bash
   npm run dev
   ```

3. **Open the Dashboard**
   Navigate to `http://localhost:5173` to experience the Unspool Emulator.
